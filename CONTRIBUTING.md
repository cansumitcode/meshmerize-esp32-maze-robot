# Contributing

Keep the Wokwi files at the repository root and preserve the documented GPIO map unless a change is explicitly explained. Run the firmware harness and diagram validator before submitting a change.

For behavior changes, include the triggering sensor sequence, expected state transition and observed result. Add regression coverage against the actual sketch where practical. Separate host-test evidence, Wokwi evidence and physical hardware measurements.

Do not commit credentials, private documents, build binaries or machine-specific paths. Do not report simulated PWM as measured RPM or claim maze-solving performance from scripted sensor inputs.

No license has been selected; discuss reuse and contribution terms with the repository owner before submitting substantial external code.
